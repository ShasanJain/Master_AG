# 🚀 Master_AG Incubator

## Upcoming Projects & Ideas

### 1. Autonomous Journalist Command Center (Web UI)
- **Status:** Incubating
- **Description:** A standalone Next.js / React dashboard that runs on `localhost:3000`. It will act as the "Control Center" for the Ghost headless CMS and local LLM pipeline.
- **Features:** 
  - Input field for topic generation.
  - Model selector (Llama3.2, Hermes3, LTX-2, ACE-Step).
  - Background orchestration of Python scripts.
  - Live preview of the published Ghost article.
- **Architecture:** Complete Headless UI, decoupling the LLM generation from the Ghost CMS backend.
