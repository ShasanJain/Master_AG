# UI Design System - VillageOS

## 1 Design Token Palette
To create a premium UI feel inside Google Sheets, use these specific hexadecimal color codes:

| Token Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Dark Primary** | `#1E293B` | Background headers and sidebar title containers |
| **Accent Blue** | `#3B82F6` | Primary action buttons and highlighted values |
| **Accent Green** | `#10B981` | Positive production rates and complete status |
| **Alert Red** | `#EF4444` | Negative crop warnings and error limits |
| **Light Gray** | `#F8FAFC` | Dashboard card body background colors |
| **Border Slate** | `#E2E8F0` | Thin lines separating tables |

## 2 Typography Guidelines
*   **Primary Font:** `Inter` or `Outfit`
*   **Sizes:**
    *   Dashboard Title: 16pt Bold
    *   Card Values: 14pt Semi-Bold
    *   Table Headers: 10pt Semi-Bold (Uppercase)
    *   Data Cells: 9pt Regular

## 3 Formatting Rules
*   Enable alternating row colors with very light grey (`#F1F5F9`) and white.
*   Format numbers cleanly (e.g., `12,500` instead of `12500`).
*   Disable standard gridlines in Google Sheets view settings.
