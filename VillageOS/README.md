# VillageOS

VillageOS is an advanced planning companion and optimization suite for *Travian: Legends*, designed as a software-grade, version-controlled spreadsheet and web system.

## Repository Structure

```
VillageOS/
├── docs/                     # Product Requirements and Architectural Specifications
│   ├── PRD.md                # 22-section Comprehensive Product Requirements
│   ├── Product Vision.md     # Vision, Mission, and Success Metrics
│   ├── User Stories.md       # User Scenarios, Personas, and Flows
│   ├── Roadmap.md            # High-Level Schedule and Milestone Planning
│   ├── Google Sheets Spec.md # UI, Color, Styling, Layout, and Cards
│   ├── Formula Engine.md     # Mathematics, Calculations, and Lookup Sheets
│   ├── AI Rec Engine.md      # Optimizer Logic, Priority Rules, and Prompts
│   ├── Screenshot Rec.md     # OCR coordinates, pre-processing, and mappings
│   ├── UI Design System.md   # Palette tokens, layout systems, typography
│   └── Changelog.md          # Log of architectural and document revisions
│
├── sheets/                   # Spreadsheet Assets, Icons, and Templates
│   ├── VillageOS_v1.xlsx     # The core Google Sheets template (as Excel)
│   └── README.md             # Sheet assets guide
│
├── appscript/                # Google Apps Script code (Automation and Buttons)
│   └── README.md

├── web/                      # React / Firebase Web Dashboard

│

```

## Milestone Roadmap

*   **Milestone 1 — Product Design**: Comprehensive documentation, UX specs, sheet schemas, formula architecture, and roadmap.
*   **Milestone 2 — Google Sheets MVP**: Dynamic dashboard, economy models, hero trackers, and daily logs with full formula verification.
*   **Milestone 3 — AI Workflow**: Screenshot upload → analysis → recommendation engine.
*   **Milestone 4 — Apps Script Integration**: Macro automation, custom UI controls, and APIs.
*   **Milestone 5 — Web Dashboard**: React and Firebase responsive interface.
*   **Milestone 6 — OCR System**: Automated parsing of screenshots.
*   **Milestone 7 — AI Coach**: recommendation models and heuristics.
*   **Milestone 8 — VillageOS v1.0**: Public Release.
